An opinionated take. If your site is small, skip the icon library and draw the
icons you actually use. This site imported 54 icons from Phosphor. I replaced
them with a set I drew myself, and the package is gone.

Every icon now looks like the site, there is one weight, and server and client
components import from the same path. The drawing rules are Lucide's: a 24 unit
grid with 2 units of padding. If you have hundreds of icons or no designer, keep
the library.

All 82 are on [the icons page](/icons).
